## C. Distinguishing adjacent systems

| Confusion | Test that separates them |
|---|---|
| Mating vs reproduction | Mating is partner selection/relationship formation; reproduction is entity creation and inheritance. |
| Family vs lineage | Family requires social/recognition/care edges; lineage requires ancestry edges. |
| Species vs culture | Species shares inherited genome; culture shares acquired information. |
| Group vs tribe | Group is one membership/territory registry; tribe requires federation or shared identity across groups. |
| Tribe vs clan | Clan emphasizes descent/kin; tribe emphasizes wider identity/alliance. |
| Nation vs civilization | Nation is governance/territory; civilization is cumulative institutions, infrastructure, culture, and multi-epoch persistence. |
| Economy vs treasury | Treasury is one balance; economy is production, exchange, scarcity, prices, and feedback. |
| Structure vs infrastructure | A structure is geometry/field; infrastructure is a maintained network with function and ownership. |
| Analytics regime vs runtime law | A regime is a measured cluster; a law is a causal dispatch path. |
