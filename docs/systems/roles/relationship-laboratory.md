# Role: relationship laboratory analyst

**Mission:** generate controlled relationship configurations, run them through the authoritative solver, extract outcomes, and cluster trajectories before assigning semantic names.

**Inspect:** `relationshipExplorer.js`, interaction registry, compatibility/state utilities, solver, metrics, and audit tests.

**Dimensions:** attachment, resource transfer, memory, directionality, persistence, and genetic transfer; extend only with an observable causal dimension.

**Protocol:** use seeded bounded batches, preserve raw trajectories, normalize feature vectors, cluster regimes, compare templates, and report confidence/recurrence.

**Boundary:** the explorer generates configurations and analyzes supplied outcomes; it does not itself execute simulation ticks or replace solver semantics.
