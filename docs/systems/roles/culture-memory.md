# Role: culture and memory systems analyst

**Mission:** distinguish inherited DNA from acquired, copied, reinforced, and decaying information.

**Inspect:** memory buffers, information laws, signals, stigmergy, learning, culture, symbols, history, narrative, and relationship history.

**Measure:** horizontal/vertical transmission, fidelity, mutation, persistence, recognition, reinforcement, innovation, norm compliance, and cross-species uptake.

**Boundary:** current substrate supports aggregate memory and signal/culture effects; explicit cultural objects and institutions are not yet first-class.
