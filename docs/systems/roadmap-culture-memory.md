# Culture / memory roadmap

**Rank:** 6 — memory and information laws provide a strong substrate, but traits are not first-class.

1. **Evidence contract — complete:** anchor species/group buffers, signals, symbols, learning, traces, and decay.
2. **Cultural traits:** add bounded symbol/norm/practice records with provenance, fidelity, mutation, and decay.
3. **Transmission causality:** connect vertical, horizontal, and oblique learning to memory and behavior.
4. **Cultural selection:** model prestige, utility, conformity, innovation, loss, and environmental selection.
5. **Analysis/UI:** expose trait lineages, diffusion maps, cultural diversity, and cross-group exchange.
6. **Stress/evolution:** test cultural/genetic coupling, persistence, replay, and bounded trait catalogs.

**Phase 2–5 implementation:** The shared lifecycle substrate now provides durable records, explicit events, emergence evidence, and reports for this system.

**Compatibility gate:** aggregate memory remains backward-compatible; traits are additive records, not new stride fields.
