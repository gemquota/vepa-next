# Infrastructure roadmap

**Rank:** 11 — construction, artifacts, infrastructure grids, and mega-project proxies exist.

1. **Evidence contract — complete:** anchor construction progress, structures, artifacts, grids, fields, ownership candidates, and maintenance gaps.
2. **Durable structure records:** add stable IDs, geometry, type, owner, dependencies, creation, damage, and removal state.
3. **Network causality:** connect roads, hubs, grids, extraction, trade, defense, and maintenance to system outcomes.
4. **Collective engineering:** support specialization, projects, failure cascades, repair, expansion, and exaptation.
5. **Analysis/UI:** map infrastructure topology, ownership, function, age, resilience, and resource cost.
6. **Stress/evolution:** test dense worlds, destruction/rebuild cycles, persistence, and field/structure parity.

**Phase 2–5 implementation:** The shared lifecycle substrate now provides durable records, explicit events, emergence evidence, and reports for this system.

**Compatibility gate:** field writes remain physics effects; durable objects become an additive registry with explicit lifecycle.
