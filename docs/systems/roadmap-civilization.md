# Civilization roadmap

**Rank:** 5 — economy, governance, construction, infrastructure, artifacts, and epochs form a proxy.

1. **Evidence contract — complete:** unify source anchors for accumulation, specialization, institutions, infrastructure, culture, and multi-epoch persistence.
2. **Civilization projection:** create a derived record aggregating groups, structures, resources, artifacts, and epoch history.
3. **Cumulative continuity:** connect knowledge, infrastructure maintenance, cultural traits, and member turnover across epochs.
4. **Development dynamics:** model specialization, urbanization, collapse, recovery, expansion, and exaptation from evidence.
5. **Analysis/UI:** provide civilization timelines, capability matrices, causal transitions, and comparative histories.
6. **Stress/evolution:** run long-duration worlds and validate collapse/recovery without making labels hard-coded laws.

**Phase 2–5 implementation:** The shared lifecycle substrate now provides durable records, explicit events, emergence evidence, and reports for this system.

**Compatibility gate:** civilization remains an observer-level synthesis; economy, governance, and infrastructure retain ownership of their state.
