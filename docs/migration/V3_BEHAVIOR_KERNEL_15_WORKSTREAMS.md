# V3 behavior kernel — 15-workstream integration

This change is the next implementation layer after the deterministic identity and
random draw contracts. It applies normalized V3-inspired state mutations to the
VEPA Next 100-slot layout. It does **not** claim full V3 worker parity.

## The 15 workstreams

1. Senescence death — per-particle death gate; marks dead, zeroes mass, retires identity.
2. Genotype drift — per-particle gate, deterministic trait selection and signed delta in the 42-slot DNA cache.
3. Isomerization — per-particle gate and deterministic species selection.
4. Reproduction gate — one world-scoped gate per enabled pass.
5. Child initialization — generation-aware identity allocated before child-keyed position/velocity/species draws.
6. Heat — per-particle three-axis velocity jitter.
7. Cold — deterministic velocity damping.
8. Radiation — non-negative mass loss.
9. Sublimation — entropy/trait threshold, mass loss and energy gain.
10. Melt — energy-scaled three-axis jitter.
11. Boil — energy threshold, three-axis jitter and mass loss.
12. Convection — vertical acceleration from normalized heat output.
13. Intrinsic jitter — entropy/trait-scaled three-axis jitter.
14. Chaos — per-particle probability gate and lazy vector consumption.
15. Pair chemistry — canonical pair allotropy, dimensional phase-through and exothermic heat.

## Contract

- Every feature is opt-in through `config.features`; disabled features consume no draws.
- All probabilities, scales, thresholds and world dimensions are explicit caller inputs.
  The kernel does not infer legacy V3 DNA offsets, world law flags, or hidden defaults.
- The input pair list must be generated by the authoritative neighbor traversal.
  Pair identity is canonical; one-sided mutation ownership remains the caller's choice.
- Identity allocator and random-stream snapshots must be persisted atomically with
  particle state using the existing execution snapshot contract.
- This module is a behavior pass, not a complete solver replacement. The caller
  controls pass ordering relative to forces, integration, collision and rendering.
- V3 source parity still requires canonical V3 fixtures, exact legacy parameter
  mapping, and differential replay tests. No claim of full V3 parity is made.

## Verification

Contract tests cover repeatability, disabled-feature draw isolation, generation
increments on reproduction, retirement on mass exhaustion, and pair-order
invariance. Full repository CI remains the authoritative merge gate.
