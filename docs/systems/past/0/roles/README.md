# VEPA systems roles

These role files are reusable prompts/specifications for agents or analysts. Each role must distinguish source evidence, inferred behavior, and proposed capability. None of these roles implies that the named system is currently implemented.

## Role contract

Every role should:

- inventory runtime sources and state owners;
- state formation, maintenance, failure, and continuity semantics;
- distinguish entity state from relationship state and analytics;
- use existing constants and registries before proposing new storage;
- define measurable experiments and falsifiable acceptance criteria;
- report partial implementation honestly;
- avoid treating labels as causal laws.
