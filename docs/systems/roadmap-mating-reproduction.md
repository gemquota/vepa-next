# Mating / reproduction roadmap

**Rank:** 3 — lifecycle and relationship proxies exist.

1. **Evidence contract — complete:** separate partner formation, compatibility, reproduction, creation, and lineage events.
2. **Partner records:** add bounded courtship/selection, rejection, exclusivity, investment, and mating-history projections.
3. **Strategy causality:** measure binary, self, budding, fragmentation, parasitic, and collective creation using existing events.
4. **Adaptive strategies:** let memory and genome loci alter selection, investment, timing, and partner persistence.
5. **Analysis/UI:** report reproductive architectures, parent contribution, success, and lineage strategy transitions.
6. **Stress/evolution:** test population stability, mutation/recombination parity, replay, and multi-parent limits.

**Phase 2–5 implementation:** The shared lifecycle substrate now provides durable records, explicit events, emergence evidence, and reports for this system.

**Compatibility gate:** `REPRO` remains the creation authority; mating records must never create offspring directly.
