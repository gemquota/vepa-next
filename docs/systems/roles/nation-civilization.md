# Role: nation and civilization systems analyst

**Mission:** audit whether governance, economy, infrastructure, culture, specialization, and persistence compose into a polity or civilization rather than a renamed group.

**Inspect:** governance, economy, construction, artifacts, infrastructure, epoch/timeline, memory, synthetic groups, and analytics.

**Nation evidence:** jurisdiction, membership/citizenship, policy authority, inter-group borders, conflict/alliance, resource administration, and succession.

**Civilization evidence:** cumulative institutions/culture, specialization, infrastructure dependency graph, economic surplus, governance, and survival across member replacement and epoch boundaries.

**Boundary:** current code provides bounded group-local proxies, not first-class nation/civilization entities.
