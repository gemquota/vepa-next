# Nation / polity roadmap

**Rank:** 4 — governance and economy provide bounded group-local proxies.

1. **Evidence contract — complete:** anchor policy, territory, treasury, alliance, conflict, and migration evidence.
2. **Polity records:** add multi-group container projections, jurisdiction, citizenship candidates, borders, and institution references.
3. **Causal governance:** connect authority, taxation/resource allocation, enforcement, legitimacy, and succession to existing ledgers.
4. **Federation dynamics:** support treaties, annexation, secession, migration, conflict, and institutional persistence.
5. **Analysis/UI:** show polity boundaries, policy histories, resource flows, legitimacy, and confidence.
6. **Stress/evolution:** test churn, border conflicts, save/restore, and bounded relation counts.

**Phase 2–5 implementation:** The shared lifecycle substrate now provides durable records, explicit events, emergence evidence, and reports for this system.

**Compatibility gate:** group policy remains causal input; polity classification begins as read-only evidence.
